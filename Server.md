# netScope Server

![netScope Server](https://www.netscope.de/fileadmin/images/netScopeServer/99mikroTransparentHistogram.png)

## Analysis

netScope Server is the most complete member of the product family. It is designed for organizations that want to store, organize and share WSI data through a managed on-premises system.

The system uses IIS and provides administration through a browser. It supports users, groups, roles, SAML 2.0 single sign-on and detailed permissions. There is also an audit trail for tracking changes. NnetScope


The WebViewer can display annotations and quantification from netScope Viewer, work with fluorescence settings, select Z planes and time points, and allow users to comment and collaborate.

## Strengths

- Centralized WSI management
- Browser-based WebViewer
- Detailed permissions
- SAML 2.0
- Audit trail
- User and group management
- Annotations and comments
- Collaboration
- Existing folder structures can be integrated
- CSV/XLS data export

The permission system is especially useful for larger groups. More than 60 individual file permissions can be combined into templates, which gives administrators quite a lot of control. NnetScope


## Weak points

Server is obviously more complicated than Desk or Cloud. It requires server infrastructure and administration, so it is probably overkill for a very small group.

The amount of functionality can also make the system feel slightly dense. There is a lot going on, and not every user will need all of it.

Some terminology and documentation could be polished a little more. It occasionally feels like a technically mature product that has grown over time rather than one designed all at once.

## Conclusion

Server is the product that makes the most sense when netScope becomes shared institutional infrastructure.

It is not the simplest option, but it provides much more control than the lightweight networking products and should suit organizations with an existing Windows server environment.
