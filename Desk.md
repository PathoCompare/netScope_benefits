# netScope Desk

![netScope Desk](https://www.netscope.de/fileadmin/images/Desk/withoutSoftware_01.png)

## Analysis

netScope Desk is the simplest way of sharing slides over a local network.

The basic concept is straightforward: install Desk on a workstation, select the folder containing the slides, and allow other netScope Viewer users to access them. This avoids copying large WSI files from one machine to another. NnetScope


## Strengths

- Simple setup
- Uses existing workstation storage
- Avoids copying large slides
- Local network access
- Can be used through suitable VPN connections
- Easy to understand

For a small laboratory this may be all that is needed.

## Weak points

The biggest limitation is that the local user has to remain logged in. If that workstation is shut down or the user logs out, clients lose access.

Permissions are also inherited from the local user, so Desk does not provide the same administrative control as Group or Server.

This makes Desk less suitable as a permanent central repository.

## Conclusion

Desk is deliberately simple, and that is mostly its advantage. It is a useful solution when a few people need access to slides without introducing another server.

Once the number of users or the importance of the data increases, Group or Server starts to make more sense.

**In short: simple, useful and limited in exactly the ways you would expect.**
