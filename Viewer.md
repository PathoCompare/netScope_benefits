# netScope Viewer

![netScope Viewer](https://www.netscope.de/fileadmin/_processed_/6/5/csm_09_Directory_Browsing_1a3381feee.jpg)

## Analysis

netScope Viewer is the core application in the product family. It is a Windows desktop viewer for whole-slide images and microscopy data, with considerably more functionality than a basic image viewer.

The application provides directory browsing, thumbnails, searching, ratings, comments, annotations and measurements. Multiple slides can be linked so that zooming or changing the viewed area can be done together.

Fluorescence work is one of the more interesting areas. Individual channels can be selected and adjusted, while histogram and display tools provide a reasonable amount of control. Z-stack and T-stack data are supported as well. NnetScope


The export system is also practical. Snapshots and selected image areas can be exported without having to use another application.

## Strengths

- Broad microscopy compatibility
- Good handling of large WSI files
- Useful fluorescence controls
- Z-stack and T-stack support
- Annotations and measurements
- Multiple-slide linking
- Flexible export and snapshots

The biggest advantage is probably that the application can work directly with the original slide data rather than requiring everything to be converted first.

## Weak points

The interface is functional rather than especially modern. Some controls look like they have been around for a while, and there are quite a few options to learn.

It is also primarily a Windows product. Wine and CrossOver provide alternatives, but native support for other desktop platforms would make it easier to deploy.

There are a few small wording and presentation quirks in the documentation too. Nothing serious, just slightly unpolished.

## Conclusion

Viewer is probably the strongest individual netScope product. It does not try to reinvent the microscope viewer, but it covers a surprisingly large number of practical tasks.

For people dealing with slides from different scanner systems, the compatibility alone makes it worth looking at.

**Overall: capable and practical, with a slightly old-school interface.**
